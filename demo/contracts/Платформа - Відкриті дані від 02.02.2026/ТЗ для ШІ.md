# Технічне завдання: Платформа: Відкриті дані

Текстова версія для ШІ. Джерело: `Оригінали/Договір від 02.02.2026 (без підписів).pdf`, Додаток 1. **ДЕМО-ДОКУМЕНТ, дані вигадані.**

**Що звірено.** Номер договору ДС-02/02-26 від 02.02.2026; замовник — Державна агенція «ДемоСервіс»; вартість 7 400 000,00 грн (з ПДВ); гарантія: 12 календарних місяців від дати акта КП (передбачено договором).

---

## 1. Мета

Метою проєкту є розроблення платформи публікації та аналітики відкритих даних Агенції.

## 2. Обсяг робіт

1. Каталог наборів даних і API для розробників
2. Конвеєри оновлення даних (ETL)
3. Аналітичні панелі й візуалізації
4. Відповідність національним вимогам до відкритих даних

## 3. Технології

Python, Django, PostgreSQL, ClickHouse, Apache Airflow, React

## 4. Нефункціональні вимоги

- Доступність: WCAG 2.1 рівня AA, перевірка автоматизованими інструментами.
- Безпека: захищені канали, журналювання подій, розмежування прав доступу, резервне копіювання.
- Продуктивність: до 500 одночасних користувачів, час відповіді сторінки до 2 с.

## 5. Етапи і вартість

- Етап 1. Аналіз і проєктування: 1 800 000,00 грн, строк 30.05.2026
- Етап 2. Розроблення і впровадження: 5 600 000,00 грн

## 6. Результати робіт

Комп'ютерна програма, вихідні коди, технічна й експлуатаційна документація, інструкції користувача, звіт про тестування.

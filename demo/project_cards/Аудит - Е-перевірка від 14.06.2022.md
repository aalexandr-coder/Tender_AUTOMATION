## 3. Предмет

Послуги з розроблення програмного забезпечення інформаційної системи електронних перевірок (завдання 3).

## 4. Обсяг за ТЗ

- Electronic planning and registration of inspections
- Risk-based selection of inspected entities
- Inspector mobile checklist (offline mode)
- Integration with the state business register via data exchange gateway
- Security audit and penetration testing before go-live

## 5. Технології

Java 11, Spring Boot, Oracle DB, Angular, Jenkins (за ТЗ, розділ 3).

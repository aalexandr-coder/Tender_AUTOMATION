## 3. Предмет

Розроблення та впровадження вебпорталу «е-черга» для запису громадян на прийом до територіальних підрозділів агенції.

## 4. Обсяг за ТЗ

- Особистий кабінет громадянина й електронний запис на прийом
- Адмінпанель оператора територіального підрозділу
- Інтеграція з реєстром послуг через шлюз обміну даними
- Сповіщення SMS і e-mail про статус запису
- Відповідність вимогам вебдоступності WCAG 2.1 AA
- Захист каналів зв'язку, журналювання подій, розмежування ролей

## 5. Технології

Java 17, Spring Boot, PostgreSQL, React, Docker, Kubernetes, GitLab CI/CD (за ТЗ, розділ 3).

## 1. Objective

To develop and deploy: software development services for the e-inspection information system (Task 3).

## 2. Scope of work

1. Electronic planning and registration of inspections
2. Risk-based selection of inspected entities
3. Inspector mobile checklist (offline mode)
4. Integration with the state business register via data exchange gateway
5. Security audit and penetration testing before go-live

## 3. Technologies

Java 11, Spring Boot, Oracle DB, Angular, Jenkins

## 4. Non-functional requirements

- Accessibility: WCAG 2.1 level AA, automated checks.
- Security: protected channels, event logging, role-based access, backups.
- Performance: up to 500 concurrent users, page response time under 2 s.
